# 🎮 Rock Paper Scissors GUI Game

An interactive, graphical Rock Paper Scissors game built with Python using `Tkinter` and `Pillow` (PIL). Play against an automated computer opponent with real-time score tracking and custom image displays.

Developed as part of my software development internship at **Hexsoftware**.

---

## 🌟 Features

* **Graphical User Interface:** Interactive desktop window built using Python's Tkinter framework.
* **Real-Time Score Tracking:** Displays dynamic score updates for both the Player and the Computer.
* **Visual Hand Gestures:** Displays corresponding image assets for Rock, Paper, and Scissors choices for each round.
* **Automated Opponent:** Computer moves are selected randomly using Python's `random.randint`.
* **Relative Path Management:** Uses `os.path` to ensure reliable image asset loading across different directory setups.

---

## 🛠️ Tech Stack & Concepts

* **Language:** Python 3.x
* **GUI Library:** `tkinter'
* **Image Processing:** `Pillow` (`PIL` / `ImageTk`)
* **Core Concepts:** Event-Driven Programming, Conditional Logic, Dynamic State Updates, Directory Pathing
