🎮 **Rock Paper Scissors Game**

An interactive graphical user interface (GUI) desktop application built with Python and Tkinter that lets you battle against a computer opponent in a classic hand-game match.

✨ **Features**

* 🎨 **Interactive GUI:** Dynamic black-themed interface featuring custom hand-gesture graphics for both the player and computer.


* 🤖 **Randomized AI:** Powered by Python's `random.randint` to ensure unpredictable computer choices every round.


* 🏆 **Live Score Tracker:** Keeps active real-time track of player and computer scores throughout your gaming session.


* ⚡ **Instant Results:** Instantly detects wins, losses, or ties and displays result messages on screen.



📋 **Requirements**

* 🐍 Python 3.x


* 🖼️ `Pillow` library for image handling (`pip install Pillow`)



📁 **Project Structure**

```text
.
├── 📄 main.py          # Script containing GUI logic, event handlers, and score tracking
├── ✊ rock1.png        # Hand icon for player's Rock choice
├── ✊ rock2.png        # Hand icon for computer's Rock choice
├── ✋ paper1.png       # Hand icon for computer's Paper choice
├── ✋ paper2.png       # Hand icon for player's Paper choice
├── ✌️ scissor1.png     # Hand icon for player's Scissor choice
└── ✌️ scissor2.png     # Hand icon for computer's Scissor choice

```

🚀 **How to Run**

1. 📥 **Clone / Download:** Download the source code and keep all `.png` icon files in the same project directory.


2. 📦 **Install Dependencies:**
```bash
pip install Pillow

```


3. ▶️ **Execute the App:**
```bash
python main.py

```



⚙️ **How It Works**

* 🔘 **Pick Your Gesture:** Click **ROCK** ✊, **PAPER** ✋, or **SCISSOR** ✌️ to select your move.


* 🎲 **Computer Response:** The computer generates a move and updates its image icon automatically.


* ⚖️ **Game Logic:** Evaluates choices (Rock beats Scissors, Scissors beats Paper, Paper beats Rock).


* 📊 **Score Update:** Awards 1 point to the winner's scoreboard and prints the outcome message.
